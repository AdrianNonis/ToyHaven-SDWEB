TOY HAVEN - BEGINNER WEBSITE

Open this folder in Visual Studio Code.
Use Live Server and open index.html.

Structure:
- 6 HTML pages
- css/style.css
- js/products.js = product data
- js/script.js = website functions
- images = simple local SVG product images
- manifest.json and sw.js = basic PWA files

The code intentionally uses basic first-year JavaScript: functions, arrays, for loops, if statements, event listeners, DOM methods and localStorage.
