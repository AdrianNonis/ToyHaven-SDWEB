TOY HAVEN - CODE COMMENTS GUIDE
================================

This version of the project has educational comments added throughout the HTML,
CSS and JavaScript files. The comments explain:
- what each main block does,
- why it is needed,
- where the result appears on the running website,
- and how important beginner JavaScript commands are being used.

IMPORTANT ABOUT manifest.json
-----------------------------
The manifest.json file intentionally DOES NOT contain comments.
Standard JSON does not allow comments. Adding // or /* */ comments inside
manifest.json could make the PWA manifest invalid.

What each manifest.json setting means:
- "name": Full PWA/app name.
- "short_name": Shorter name that can be used by the device.
- "start_url": First page opened when the PWA starts.
- "display": "standalone" makes an installed PWA feel more like an app.
- "background_color": Background colour used by the PWA.
- "theme_color": Main browser/app theme colour.
- "icons": Tells the PWA where its application icon is stored.

TIP
---
HTML comments use: <!-- comment -->
CSS comments use:  /* comment */
JavaScript comments use: // comment   or   /* comment */
JSON normally does not support comments.
